# أبو سعد — كود نيمز أونلاين

نسخة أونلاين فعلية: غرف + رابط مشاركة + مزامنة لحظية بين اللاعبين.

## التشغيل على جهازك
1. ثبّت Node.js.
2. افتح الطرفية داخل المجلد.
3. شغّل:
   npm install
   npm start
4. افتح http://localhost:3000

## نشرها على الإنترنت
المشروع جاهز لخدمات استضافة Node مثل Render:
- ارفع المجلد إلى GitHub.
- أنشئ Web Service من المستودع.
- Build: npm install
- Start: npm start

بعد النشر سيطلع لك رابط عام ترسله لخويانك.

ملاحظة: الغرف مؤقتة وتعيش طالما فيها لاعبين/اتصال بالسيرفر؛ لا توجد قاعدة بيانات دائمة.
